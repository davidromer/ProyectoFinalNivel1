# ProyectoFinalNivel1

Proyecto Final Nivel 1 para la certificación de python Junior.

## Sistema de gestión de usuarios

Se implementó un sistema en Python 3 con:

- Manejo de archivo de texto (`usuarios.txt`) para persistencia.
- Validación de datos de entrada (ID, nombre, email y edad).
- Captura de errores de validación y de E/S.
- Operaciones básicas: agregar, listar, buscar y eliminar usuarios.

## Ejecutar la aplicación

```bash
python user_management.py
```

## Ejecutar pruebas

```bash
python -m unittest
```
